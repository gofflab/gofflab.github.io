Software

pySeq 2501

Author: Chaichontat Sriworarat

Control your HiSeq 2000/2500 with ease. pyseq2501 adapts and refactors the PySeq2500 controller software, turning an aging, unsupported HiSeq 2500 into a flexible fluidics and microscopy platform for custom workflows.

TRICycle

TRICycle (Transferable Representation and Inference of Cell Cycle) is an R package for fast, universal annotation of cell cycle state in large single cell datasets. Building on projectR, it projects new single cell RNA-seq, ATAC-seq, or other data into a reference latent space and estimates each cell's continuous position along the cell cycle. It is fast and memory-efficient, needs minimal preprocessing, and requires no a priori cell annotations, so cell cycle dynamics can be explored in atlas-scale datasets.

projectR

projectR is a regression-based transfer learning tool for single cell analysis. It embeds any high-throughput molecular assay into latent spaces learned from a source dataset, so that cell types and biological features annotated in one dataset can be identified in another. Because projection preserves relative distances between samples, biologically meaningful factors stratify new data according to their underlying processes. We have used projectR to transfer cell type and state labels across datasets without prior annotation, to identify a species-specific signature of microglia, and to find a previously undescribed subpopulation of neurosecretory cells in the lung.

CummeRbund

An R/Bioconductor package for storing, manipulating, analyzing, and visualizing Cufflinks RNA-seq results. Differential expression analyses produce large, highly interrelated datasets that can be hard to navigate. CummeRbund loads the output of a cuffdiff run into an indexed SQLite database that records the relationships between genes, transcripts, transcription start sites, and coding sequences. Data for any feature, across any number of samples or conditions, can then be retrieved quickly, whether you are exploring a single gene, its isoforms, or an entire gene set.

DeCoN

The Developing Cortical Neuron Transcriptional Resource. DeCoN is a web resource for exploring deep RNA-seq profiles of sorted mouse cortical projection neurons, with isoform, gene, and gene set-level expression for callosal, subcerebral, and corticothalamic projection neurons across corticogenesis.
